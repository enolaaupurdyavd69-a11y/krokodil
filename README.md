# Крокодил и Табу 18+

Две party-игры для взрослых компаний: Telegram Mini App, открывается кнопкой в чате с ботом.
Чистые HTML/CSS/JS без сборки, хостинг на GitHub Pages.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | страница, подключает Telegram WebApp SDK |
| `app.js` | вся логика: экраны, таймер, очки, сохранение партии |
| `style.css` | оформление |
| `words/index.json` | список категорий |
| `words/<id>.json` | слова Крокодила: `[{"t": "Слово", "d": 1}]`, `d` — сложность 1–3 |
| `words/tabu/<id>.json` | карточки Табу: `[{"t": "Слово", "x": [5 запретных], "d": 1}]` |

## Как добавить слова

Открыть нужный `words/<id>.json`, дописать строки вида `{"t": "Новое слово", "d": 2},`
(у последней строки запятой нет). Новая категория: файл `words/<id>.json` и строка в `words/index.json`.

После любых правок увеличить `VER` в начале `app.js` и `?v=` в `index.html` —
иначе Telegram может показывать старую версию из кеша.

## Публикация

1. Репозиторий на GitHub (публичный) → залить эти файлы в ветку `main`.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Через 1–2 минуты игра доступна по `https://<ник>.github.io/<репозиторий>/`.

## Бот

В Telegram → @BotFather:
1. `/newbot` → имя и username нового бота.
2. `/setmenubutton` → выбрать бота → вставить ссылку GitHub Pages → текст кнопки `Играть`.

Сервер и токен бота не нужны: кнопка просто открывает страницу.

## Локальная проверка

```
python -m http.server 8765
```
и открыть http://127.0.0.1:8765/

## Мафия 18+ (бот для групп, `bot/`)

Отдельная от сайта часть: Telegram-бот ведёт Мафию в группе, у каждого игрока свой телефон.
Работает постоянным процессом на ПК (long polling) — только пока ПК включён.

| Файл | Что внутри |
|---|---|
| `bot/mafia_engine.py` | логика: роли, ночь, голосование, победа (без Telegram) |
| `bot/mafia_bot.py` | бот: набор, роли в личку, ночные кнопки, голосование, таймеры, SQLite |
| `bot/texts.py` | тексты 18+ |
| `bot/test_mafia.py` | тесты: `cd bot && python -X utf8 -m unittest -v test_mafia` |
| `bot/install_task.ps1` | автозапуск: задача Планировщика `KrokodilMafiaBot` |

Токен — в `bot/token.txt` (не в git). База партий и лог — `bot/data/` (не в git).

Как играть: добавить бота в группу → `/mafia` → все жмут «Участвую» и «Старт» в личке бота →
открывший набор жмёт «Начать игру». Чтобы мёртвые молчали, сделайте бота админом с правом
«Блокировка участников».
